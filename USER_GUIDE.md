# User Guide

RouteBook is where route knowledge lives — gate codes, parking rules, hazards, and access notes, organized by route and by stop, so that knowledge doesn't disappear when a route changes hands.

## Finding things

**Browsing**: click the RouteBook logo to see every route. Click a route to see its stops and any notes that apply to the whole route. Click a stop to see notes specific to that one location.

**Searching**: type into the search box in the top bar and press Enter. It searches every note's title and body text across every route and stop — useful when you remember part of a gate code or a customer name but not which route it's on.

## Understanding the color tabs

Every note has a colored tab on its left edge showing its category at a glance:

| Color | Category | Use for |
|---|---|---|
| Orange | Hazard | Dogs, low clearance, tight turns, PPE requirements |
| Navy | Gate Code | Keypad codes, gate/door access numbers |
| Sage green | Parking | Where to park, where not to park |
| Purple | Contact | Who to ask for, who to call |
| Tan | Access | How to get into a building/dock |
| Gray | Other | Anything that doesn't fit the above |

## Adding a new route

From the route list, click **+ New Route**. Give it a name and optional description. You can assign an existing driver, or click "+ Add a new driver instead" to create one on the spot without leaving the form.

## Adding a stop to a route

On a route's page, click **+ Add Stop**. Fill in the customer name and address — this creates both the physical location and the stop in one step. New stops are added to the end of the route's sequence automatically.

## Adding a note

Click **+ Add Note** on either a route page (for a note that applies to the whole route) or a stop page (for a note specific to that one location). Give it a title, the details, and pick a category — the color tab updates automatically based on what you choose.

## Attaching files

On any note's detail page, click **Add file** to attach a photo, PDF, Word document, spreadsheet, plain text file, or video. Supported: most common image formats, PDF, Word (.doc/.docx), plain text, Excel (.xls/.xlsx), and video (MP4, MOV, WebM, AVI). Photos and documents are capped at 25MB; videos at 250MB.

Once uploaded, click a file's name to open/download it. Click **Remove** to delete it — this removes the file permanently from storage, not just from the list.

## What happens if something looks wrong

If a page shows an error message instead of loading normally, it usually means either the backend isn't reachable, or something you tried to save didn't pass validation (e.g. a required field was left blank). Error messages are meant to say plainly what went wrong — if one doesn't make sense, that's worth flagging as a bug.
